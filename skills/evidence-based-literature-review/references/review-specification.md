# Review Specification: Topic, Defaults, Review Type | مواصفات المراجعة

## English

### Step 1 — Topic and working language
Obtain the exact topic, question, or working title and determine whether it must be preserved verbatim or may be refined academically.

Language rule:
- Arabic request/topic → Arabic workflow.
- English request/topic → English workflow.
- Mixed/ambiguous → infer from context; ask only if genuinely unclear.
- Preserve the confirmed final-document language.
- Bibliographic metadata stays in its original language/script.

### Step 2 — Smart defaults or customization
The topic/title is the only mandatory starting input. Offer **Use smart defaults** or **Customize**.

| Setting | Default |
|---|---|
| References | 50 |
| Citation style | APA 7 |
| Academic level | PhD |
| Review type | Critical narrative |
| Structure | Thematic |
| Date range | No hard limit; foundational + current evidence |
| Length | ~4,000–6,000 words |
| Theoretical lens | Let evidence reveal dominant frameworks |
| Purpose | Thesis/dissertation chapter |
| Discipline | Infer from topic |
| Evidence matrix | Required |
| Independent DOI/metadata verification | Required where feasible |
| Critical appraisal | Required |
| Gap taxonomy | Required |
| Citation audit | Required |
| Grey literature | Exclude unless relevant |
| Language | Working language |

Customize only what is needed: reference count, citation style, level, review type, structure, outline, date range, length, theory, purpose, discipline, population/context, geography, languages, publication types, grey literature, PRISMA rigor, or meta-analysis.

Do not promise meta-analysis until compatible quantitative data are confirmed.

### Step 3 — Correctly classify review type
- **Narrative:** broad conceptual synthesis; exhaustive reproducibility is not the principal objective.
- **Critical:** evaluates assumptions, theories, methods, contradictions, and conceptual development.
- **Integrative:** combines diverse empirical/theoretical designs.
- **Scoping:** maps breadth, concepts, evidence types, and gaps.
- **Systematic:** requires a focused question, predefined eligibility, reproducible search, documented sources, deduplication, structured screening, full-text eligibility, transparent synthesis, and appropriate quality/risk-of-bias assessment.
- **PRISMA-aligned:** use the current applicable PRISMA framework and report required items; never relabel a lightweight narrative search as PRISMA.
- **Meta-analysis:** separate quantitative synthesis requiring compatible extractable numerical data and an appropriate statistical model.

## العربية

### الخطوة الأولى — الموضوع واللغة
احصل على الموضوع/السؤال/العنوان، وحدد هل يجب الحفاظ على العنوان أم يمكن تحسينه.
- العربي ← سير عمل عربي.
- الإنجليزي ← سير عمل إنجليزي.
- المختلط ← استدل من السياق واسأل عند الغموض الحقيقي فقط.
- حافظ على لغة المستند النهائي المؤكدة.
- تبقى بيانات المراجع بلغتها الأصلية.

### الخطوة الثانية — الإعدادات الذكية أو التخصيص
الإعدادات الافتراضية:
- 50 مرجعًا؛
- APA 7؛
- مستوى دكتوراه؛
- مراجعة سردية نقدية؛
- بنية موضوعية؛
- دون حد زمني صارم مع الجمع بين التأسيسي والحديث؛
- 4000–6000 كلمة؛
- تُستخرج الأطر النظرية من الأدلة؛
- فصل رسالة/أطروحة؛
- مصفوفة أدلة إلزامية؛
- تحقق مستقل من DOI والبيانات متى أمكن؛
- تقييم جودة إلزامي؛
- تصنيف فجوات وتدقيق استشهادات إلزاميان؛
- الأدبيات الرمادية مستبعدة ما لم تكن ذات صلة.

خصص عند الحاجة: العدد، التوثيق، المستوى، نوع المراجعة، الهيكل، المدى الزمني، الطول، النظرية، الغرض، التخصص، المجتمع، الجغرافيا، اللغة، نوع المنشور، الأدبيات الرمادية، PRISMA، أو Meta-analysis.

لا تعد بالتحليل البعدي قبل التأكد من ملاءمة البيانات الكمية.

### الخطوة الثالثة — تحديد نوع المراجعة
- **سردية:** تركيب مفاهيمي واسع.
- **نقدية:** نقد الافتراضات والنظريات والمناهج والتناقضات.
- **تكاملية:** دمج تصاميم متنوعة.
- **استكشافية (Scoping):** رسم نطاق الحقل والمفاهيم وأنواع الأدلة والفجوات.
- **منهجية:** سؤال محدد + أهلية مسبقة + بحث قابل لإعادة الإنتاج + مصادر موثقة + إزالة تكرار + فرز + نص كامل + تقييم جودة مناسب + تركيب شفاف.
- **PRISMA:** لا تستخدم التسمية إلا مع تنفيذ المتطلبات الحالية الملائمة.
- **Meta-analysis:** تركيب كمي مستقل يتطلب بيانات رقمية متوافقة ونموذجًا إحصائيًا مناسبًا.
