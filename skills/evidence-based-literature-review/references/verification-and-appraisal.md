# Verification, Critical Appraisal and Evidence Matrix | التحقق والتقييم النقدي ومصفوفة الأدلة

## English

### Step 8 — Independent bibliographic verification
Do not treat the discovery platform as the sole bibliographic truth.

Verify where feasible: title; authors; year; source; volume/issue; pages/article number; DOI/stable ID; publication status; correction/retraction status.

**Verification hierarchy:** official publisher/journal → DOI registry/Crossref-like source → PubMed or authoritative disciplinary index → OpenAlex-like metadata → academic discovery platform.

When records disagree: investigate, prefer authoritative primary metadata, record the resolved version, mark unresolved fields uncertain, and never guess.

A plausible-looking DOI is not verified until it resolves or matches authoritative metadata.

### Step 9 — Critical appraisal / risk of bias
Assess the **study**, not merely the journal. Select an appropriate instrument, for example:
- RoB 2 — randomized trials;
- ROBINS-I — non-randomized intervention studies;
- JBI Critical Appraisal Tools — multiple designs;
- CASP — appropriate qualitative/clinical designs;
- AMSTAR 2 — systematic reviews;
- QUADAS-2 — diagnostic accuracy;
- Newcastle–Ottawa Scale or justified validated alternative — selected observational designs;
- GRADE — certainty of a body of evidence where appropriate.

Record tool, domains, judgment, justification, and implications for synthesis. Keep journal metrics separate from study quality.

### Step 10 — Evidence matrix
Build before drafting:

| Field | Function |
|---|---|
| Study ID | Tracking |
| Author/Year | Identification |
| Title | Identification |
| DOI/stable ID | Verification |
| DOI verified | Yes/No |
| Journal/source | Bibliography |
| Country/context | Context |
| Aim | Purpose |
| Design | Method |
| Sample/population | Generalizability |
| Instruments/measures | Measurement |
| Constructs/variables | Concept mapping |
| Theory/framework | Theoretical mapping |
| Key findings | Evidence |
| Effect/association | Direction/magnitude if reported |
| Statistical details | Only if explicitly reported |
| Limitations | Critical interpretation |
| Risk of bias/quality | Appraisal |
| Theme/code | Synthesis |
| Contradictions | Divergence |
| Gap contribution | Gap mapping |
| Full-text status | Access |
| Notes | Audit trail |

Never infer missing values. Use **Not reported / Not available / Unverified**.

## العربية

### الخطوة الثامنة — التحقق الببليوجرافي المستقل
لا تعامل منصة الاكتشاف على أنها المصدر الوحيد للبيانات الببليوجرافية.

تحقق من العنوان والمؤلفين والسنة والمصدر والمجلد والعدد والصفحات وDOI وحالة النشر والسحب/التصحيح.

ترتيب الأفضلية: **الناشر الرسمي ← سجل DOI/Crossref ← فهرس تخصصي موثوق مثل PubMed ← OpenAlex وما يماثله ← منصة الاكتشاف الأكاديمية.**

عند التعارض: تحقق، رجّح المصدر الرسمي، سجّل النسخة المحسومة، وسم غير المحسوم، ولا تخمن.

DOI الذي يبدو صحيحًا لا يعد موثقًا حتى يطابق سجلًا موثوقًا.

### الخطوة التاسعة — التقييم النقدي
قيّم الدراسة نفسها. استخدم الأداة المناسبة للتصميم، مثل:
- RoB 2؛
- ROBINS-I؛
- JBI؛
- CASP؛
- AMSTAR 2؛
- QUADAS-2؛
- Newcastle–Ottawa أو بديل موثق عند الملاءمة؛
- GRADE ليقين مجموعة الأدلة عند الملاءمة.

سجّل الأداة والمجالات والحكم والمبرر وأثر الجودة في التركيب. افصل مؤشرات المجلة عن جودة الدراسة.

### الخطوة العاشرة — مصفوفة الأدلة
أنشئ قبل الكتابة حقولًا تشمل: معرف الدراسة، المؤلف/السنة، العنوان، DOI وحالة التحقق، المصدر، الدولة/السياق، الهدف، التصميم، العينة، الأدوات، المتغيرات، النظرية، النتائج، حجم/اتجاه العلاقة، الإحصاءات المصرح بها، القيود، خطر التحيز، المحور، التناقضات، مساهمة الفجوة، حالة النص الكامل، والملاحظات.

لا تستنتج البيانات المفقودة؛ استخدم **غير مذكور / غير متاح / غير متحقق منه**.
