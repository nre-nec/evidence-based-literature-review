# Systematic and PRISMA Protocol | بروتوكول المراجعة المنهجية وPRISMA

## English

### Step 14 — Systematic/PRISMA protocol
When systematic/PRISMA work is requested, document as applicable:
1. question/objectives;
2. eligibility criteria;
3. information sources;
4. exact search strategies;
5. search dates;
6. selection process;
7. extraction process;
8. data items;
9. risk-of-bias assessment;
10. effect measures;
11. synthesis methods;
12. heterogeneity handling;
13. reporting bias;
14. certainty assessment;
15. study-selection flow;
16. protocol/registration if any;
17. amendments/deviations.

Generate PRISMA flow data only from actual recorded counts (identification, duplicates, screening, exclusions, reports sought/not retrieved, full-text assessment, exclusion reasons, final inclusion).

If the available environment cannot support a genuinely reproducible systematic review, **downgrade to the strongest defensible review type** rather than falsely claiming compliance, and say so.

### Systematic/PRISMA report structure
Abstract if needed → introduction → question/objectives → methods → search → eligibility → selection → quality/risk of bias → results → study characteristics → synthesis → quality results → discussion → limitations → gaps → implications → conclusion → references → supplementary search/evidence tables as required.

## العربية

### الخطوة الرابعة عشرة — Systematic/PRISMA
وثّق عند الطلب: السؤال والأهداف، الأهلية، مصادر المعلومات، الاستراتيجيات الدقيقة، تواريخ البحث، الاختيار، الاستخراج، عناصر البيانات، خطر التحيز، مقاييس الأثر، طرق التركيب، عدم التجانس، تحيز النشر، يقين الأدلة، تدفق الدراسات، التسجيل/البروتوكول، والتعديلات.

لا تنشئ مخطط PRISMA إلا من أعداد فعلية. إذا تعذر تنفيذ مراجعة منهجية قابلة لإعادة الإنتاج، اخفض تصنيف المخرج إلى أقوى نوع يمكن الدفاع عنه بدل الادعاء الزائف، وصرّح بذلك.

### هيكل تقرير Systematic/PRISMA
ملخص عند الحاجة → مقدمة → سؤال/أهداف → منهجية → بحث → أهلية → اختيار → جودة → نتائج → خصائص الدراسات → تركيب → جودة الأدلة → مناقشة → قيود → فجوات → دلالات → خاتمة → مراجع → ملاحق عند الحاجة.
